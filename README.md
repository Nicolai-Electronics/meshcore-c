# Meshcore LoRa protocol in C

This repository contains a work in progress implenentation of the Meshcore LoRa protocol written from scratch in C without any dependencies on Platformio or C++.

The goal is to make this into both a library you can easily include in any project and simultaneously into a component for use in ESP-IDF projects.

## Other Meshcore related projects

Check out our implementation of the [Meshcore companion radio protocol in C](https://github.com/Nicolai-Electronics/meshcore-companion-radio-protocol).
